# AI Workshop - OpenEdge ABL Project

OpenEdge ABL workshop project demonstrating the Business Entity pattern against the sports2000 database.

## Contents

- `src/business/` - Business entity classes (`CustomerEntity`, `EntityFactory`) and dataset include files
- `src/` - AppBuilder window files (`CustomerWin.w`, `ItemWin.w`)
- `dump/sports2000.df` - sports2000 database schema (first 500 lines)
- `doc/` - Documentation on the business entity architecture pattern
- `.windsurf/rules/` - AI assistant rules (ABL syntax, buffers, database schema)
- `.windsurf/workflows/` - AI assistant workflows
- `.github/ISSUE_TEMPLATE/` - GitHub issue templates
- `openedge-project.json` - OpenEdge project configuration (OE 12.8)
- `build.xml` - PCT build script (sports2000 database creation)
